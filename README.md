# Lina Criativa - Thank you

Standalone English thank-you page for both accepted and declined upsells.

Vercel: Framework Other; repository root; no build command; output directory `.`. Main entrypoint: index.html. Alias: thank-you.html.

After deployment, set both final paths in the Hotmart funnel to this site URL. The page links to the Hotmart buyer area and explains email access and support. It does not verify payment, send email or grant product access. No checkout or pixel is included.
